# Entity

`Entity` is a JSX wrapper around any `three.js` class. Where [`<T.Mesh/>`](/api/components/t) is shorthand for "make me a `Mesh`", `<Entity from={Mesh}/>` says the same thing without pre-building a [`T`](/api/components/t) namespace — useful in libraries or when the class you want is only known at runtime.

You can pass a constructor

```tsx
<Entity from={Mesh}>
  <Entity from={BoxGeometry} args={[1, 1, 1]} />
  <Entity from={MeshBasicMaterial} args={[{ color: "orange" }]} />
</Entity>
```

or pass an instance

```tsx
const mesh = new Mesh(new BoxGeometry(1, 1, 1), new MeshBasicMaterial({ color: "orange" }))
<Entity from={mesh} position={[0, 0, 0]} />
```

**Props:**

- **from**: Either a three.js constructor (class) or an existing instance
- **args**: Arguments to pass to the constructor when using a class
- All other props supported by the three.js object

<details>
<summary>Typescript Interface</summary>

```tsx
interface EntityProps {
  from: Constructor | Instance
  args?: ConstructorParameters
  // Plus all THREE.js object props
}
```

</details>

## createEntity

`createEntity` creates a single typed component from one `three.js` constructor — the same primitive [`createT`](/api/components/t) uses internally to build a whole namespace. Use it directly when you need a one-off component without building a full namespace:

```tsx
import { createEntity } from "solid-three"
import { Mesh } from "three"

const MeshComponent = createEntity(Mesh)

// Equivalent to <T.Mesh /> but without the full namespace
<MeshComponent position={[0, 1, 0]}>
  ...
</MeshComponent>
```

## Manual disposal of instance-entities

When passing an instance to `<Entity from={...}/>`, disposal needs to be handled manually. This can be done via the [`autodispose`](/api/utilities/autodispose) utility.

**Wrong**

If you do not dispose of box/sphere after the component unmounts, threejs will retain the resource in memory.

```tsx
function Wrong(props: { shape: "box" | "sphere" }) {
  const box = new BoxGeometry()
  const sphere = new SphereGeometry()
  return (
    <Show when={props.shape === "box"} fallback={<Entity from={sphere} />}>
      <Entity from={box} />
    </Show>
  )
}
```

**Good**

By wrapping `BoxGeometry` and `SphereGeometry` in `autodispose`, the resources are automatically disposed once the component cleans up.

```tsx
function Good(props: { shape: "box" | "sphere" }) {
  const box = autodispose(new BoxGeometry())
  const sphere = autodispose(new SphereGeometry())
  return (
    <Show when={props.shape === "box"} fallback={<Entity from={sphere} />}>
      <Entity from={box} />
    </Show>
  )
}
```

## Props

All `Entity` props (other than `from` and `args`) are applied via [`useProps`](/api/hooks/use-props), which handles array coercion, dashed-path nesting (`shadow-mapSize-width={1024}`), `Color` string parsing, `attach` slotting, event-listener registration, and automatic `needsUpdate` flagging. See [`useProps`](/api/hooks/use-props) for the full coercion table and `attach`/`args`/`ref` semantics.
