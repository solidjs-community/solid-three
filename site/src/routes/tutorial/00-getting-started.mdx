# Getting started

Install `solid-three` together with `three`:

```bash
npm install solid-three three
```

```bash
pnpm install solid-three three
```

```bash
yarn add solid-three three
```

`solid-js` is a peer dependency, so make sure it is already installed in your
project.

That's everything you need — head to [Your first scene](/tutorial/01-your-first-scene)
to render something.
